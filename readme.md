# GrimLite Ligma

> [!NOTE]
> This version has been reset to **1.9.3** in accordance with the latest merge from [jib-akbr/Grimlite-Li](https://github.com/jib-akbr/Grimlite-Li).


## Requirements
- .NET Framework 4.7.2 or higher
- CleanFlash (Flash Player ActiveX)
- Basic logic knowledge to design bots (`.gbot`)

## Shortcuts
- **Ctrl + C**: Copy selected commands with `.gbot` serialization
- **Ctrl + V**: Paste copied commands or an entire `.gbot`
- **Ctrl + S**: Save configuration as `.gbot`
- **Ctrl + Up / Down Arrow**: Move selected command up or down by 1 position
- **Hold Ctrl + Add Command**: Insert command above the currently selected index
- **Hold Alt + Add Command**: Alter/toggle command variant (e.g., toggle **Normal Accept Quest** to **Ghost Accept Quest**)
- **Double-click on a command**: Open the command editor
